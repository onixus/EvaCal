# EvaCal — калькулятор трудозатрат

Веб-приложение для расчёта трудозатрат в человеко-часах по этапам проекта, с автоматической
постановкой задач согласования на заказчика.

## Стек

- Next.js 14 (App Router) + TypeScript
- Prisma + SQLite (лёгкая встроенная БД, файл `prisma/dev.db`)
- Tailwind CSS

## Бизнес-логика

- Каждый шаблон опросника (админ) описывает вопросы и формулы этапов:
  `часы = базовые_часы + часы_на_единицу × значение_числового_поля`.
- При заполнении опросника пресейлом создаётся расчёт: этапы генерируются из формул шаблона
  и выстраиваются в календарный план (рабочие дни, 09:00–18:00, без выходных).
- Для каждого этапа, где исполнитель — **консультант, разработчик, инженер или аналитик**,
  автоматически добавляется задача согласования на заказчика сроком **3 рабочих дня**,
  которая блокирует начало следующего этапа.
- В каждый расчёт автоматически добавляется **РП** (руководитель проекта): 16 ч на старт и
  закрытие проекта (по 8 ч в начале и в конце Гантта) + **10% / 20% / 30%** от суммарных
  трудозатрат остальных этапов — в зависимости от значения вопроса с типом «Сложность проекта»
  (Простой / Средний / Сложный). Если такой вопрос в шаблоне не задан, используется 20% по умолчанию.
- Архитектор может редактировать и добавлять этапы, после чего график и задачи согласования
  пересчитываются заново, а затем утверждает расчёт пресейла.
- Все расчёты (включая утверждённые и старые) доступны всем — без ограничений доступа.

## Доступ (RBAC)

- **Пресейл** и **архив расчётов** (`/`, `/calculations/[id]`) открыты без входа.
- **Архитектор** (`/architect`) и **администратор** (`/admin`) требуют входа под своей ролью.
- При первом запуске (`npm run db:seed`) для ролей `architect` и `admin` генерируются случайные
  пароли. Они **один раз** выводятся в консоль и сохраняются в `credentials.local.txt`
  (в `.gitignore`, не попадает в репозиторий) — после входа смените пароль в `/account` и удалите файл.
- Роль присвоена жёстко: логин `architect` → роль «архитектор», логин `admin` → роль «админ».
  Смешивание ролей (например, доступ архитектора в `/admin`) запрещено на уровне API и страниц.

## Три интерфейса

- **`/presale`** — заполнение опросника, просмотр этапов, трудозатрат и диаграммы Ганта,
  отправка на согласование архитектору.
- **`/architect`** — просмотр расчётов на согласовании, редактирование/добавление этапов,
  утверждение расчёта.
- **`/admin`** — визуальный конструктор форм: вопросы опросника и формулы этапов.
- **`/`** и **`/calculations/[id]`** — архив всех расчётов, доступный всем.

## Запуск

```bash
cp .env.example .env
npm install
npm run db:push     # создаёт SQLite-схему
npm run db:seed     # демонстрационный шаблон, расчёт и пароли architect/admin
npm run dev
```

Приложение будет доступно на http://localhost:3000. Логины и пароли для входа в
`/architect` и `/admin` — см. вывод `npm run db:seed` или `credentials.local.txt`.
